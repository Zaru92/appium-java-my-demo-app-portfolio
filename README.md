# Appium Java My Demo App Portfolio

Cross-platform mobile UI test automation framework for Sauce Labs My Demo App,
built with Java, Appium, Maven, and TestNG.

> Project status: under active development.  
> Current milestone: deterministic Maven project bootstrap.

## Planned capabilities

- Android and iOS test execution
- Emulators, simulators, and physical devices
- Cross-platform Page Object architecture
- Positive and negative end-to-end scenarios
- Parallel execution
- TestNG groups and execution suites
- Allure reports with screenshots and videos
- Structured logging and diagnostic artifacts
- GitHub Actions CI
- Local and cloud-ready device configuration

## Technology baseline

- Java 21
- Maven Wrapper 3.9.16
- Appium Java Client
- TestNG
- Allure
- SLF4J and Logback
