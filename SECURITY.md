# Security Policy

## Supported versions

This repository is a portfolio test automation project and is not distributed as a production library. Security fixes are provided only for the latest code on the `main` branch.

| Version | Supported |
| --- | --- |
| Latest `main` | Yes |
| Older commits and branches | No |

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Use [GitHub private vulnerability reporting](https://github.com/Zaru92/appium-java-my-demo-app-portfolio/security/advisories/new) to submit a report.

Please include:

- a clear description of the vulnerability;
- the affected commit or configuration;
- steps required to reproduce the issue;
- its potential impact;
- any suggested mitigation, if available.

You can expect an initial response within seven days. Confirmed vulnerabilities will be assessed, addressed, and disclosed in a coordinated manner.

This repository tests Sauce Labs My Demo App but does not maintain the application itself. Vulnerabilities affecting the application should be reported to its maintainers.
